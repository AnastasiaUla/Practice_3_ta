# 5. Полученная КСГ

Для языка

```math
L_28 = { a^n b^m c^k | k = |n + m|, m >= 0, n >= 0, k >= 0 }
```

построена контекстно-свободная грамматика:

```text
S → aSc
S → B

B → bBc
B → λ
```

Смысл нетерминалов:
- `S` порождает n пар символов `a` и `c`, а затем передаёт управление нетерминалу `B`;
- `B` порождает m пар символов `b` и `c`, либо завершает вывод пустой строкой;
- итоговая цепочка имеет вид a^n b^m c^(n+m), что в точности соответствует заданному языку.
