# 2. Цель работы с постановкой задачи.

**Цель работы:**

Исследование автоматов с магазинной памятью, контекстно-свободных грамматик и свойств контекстно-свободных языков, а также доказательство принадлежности языков к классу контекстно-свободных.

## Вариант 12

## Часть 1

Рассматривается язык

```math
L_{12}=\{a^n b^m\mid n\ge 0,\ n\ne m\}
```

Необходимо с использованием системы JFLAP построить МПА, распознающий данный язык, либо формально доказать невозможность этого. Предложить программную реализацию МПА.

## Часть 2

Рассматривается язык

```math
L_{28}=\{a^n b^m c^k\mid k=|n+m|,\ m\ge 0,\ n\ge 0,\ k\ge 0\}
```

Необходимо с использованием системы JFLAP построить контекстно-свободную грамматику, описывающую данный язык, который может быть распознан алгоритмом перебора или управляемым пользователем, либо формально доказать невозможность этого.

## Часть 3

Рассматривается язык

```math
L_{44}=\{w\in\{a,b,c\}\mid n_a(w)=n_b(w)=n_c(w)\}
```

Для данного языка требуется с использованием леммы о разрастании контекстно-свободных языков доказать его контекстно-свободность или её отсутствие.
