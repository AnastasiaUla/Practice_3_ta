
# 7. Формальное доказательство принадлежности к классу КСЯ

Задан язык

```math
L_{44}=\{w\in\{a,b,c\}^*\mid |w|_a=|w|_b=|w|_c\}
```

на алфавите `{a,b,c}`.

Необходимо формально определить, является ли язык контекстно-свободным, используя лемму о разрастании.

## Доказательство

Язык **не является контекстно-свободным**. Докажем это методом от противного с использованием леммы о разрастании для контекстно-свободных языков.

Предположим, что язык `L_44` является контекстно-свободным. Тогда существует число `p`, такое что любую цепочку `w` из языка длины не менее `p` можно представить в виде

```math
w=uvxyz,
```

где выполняются условия

```math
|vxy|\le p,\qquad |vy|>0,
```

и для любого целого неотрицательного \(i\) цепочка

```math
uv^ixy^iz
```

принадлежит языку `L_44`.

### Выбор цепочки

Рассмотрим цепочку

```math
w=a^p b^p c^p.
```

В ней содержится ровно `p` символов каждого типа, поэтому

```math
w\in L_{44}.
```

Поскольку длина подцепочки `vxy` не превышает `p`, она не может одновременно содержать символы `a` и `c`: между ними находятся все `p` символов `b`, поэтому такая подцепочка имела бы длину не менее `p+2`.

Следовательно, подцепочки `v` и `y` могут содержать символы не более двух типов из множества `{a,b,c}`.

### Применение леммы о разрастании

Рассмотрим случай `i=0`. Тогда из исходной цепочки удаляются подцепочки `v` и `y`, и получается

```math
w'=uxz.
```

По условию леммы

```math
|vy|>0,
```

поэтому при удалении `v` и `y` исчезает хотя бы один символ.

При этом хотя бы один из трёх типов символов не содержится в удаляемых подцепочках. Количество этого символа остаётся равным `p`, тогда как количество хотя бы одного другого типа символов становится меньше `p`.

Следовательно, в цепочке `w'` количества символов `a`, `b` и `c` не равны. Значит,

```math
w'\notin L_{44}.
```

Однако лемма о разрастании требует, чтобы цепочка, полученная при `i=0`, также принадлежала языку `L_{44}`. Получено противоречие.

## Вывод

Предположение о контекстно-свободности языка оказалось неверным. Следовательно,

```math
L_{44}\notin CFL.
```

**Таким образом, язык `L_{44}` не принадлежит классу контекстно-свободных языков (КСЯ).**
